## api-rbac

##### 项目目标
1. 通用的权限管理系统,以类似微服务的形式运行
2. 包含接口有:
   - 用户登录认证
   - 用户正删改查查
   - 角色的增删改查
   - 权限的增删改查
3. 可以方便的与别的语言开发的业务集成

##### 技术栈
1. GO + Gin

##### 项目架构要求
1. 各个接口与层级代码封装边界清晰简洁
2. 该项目要最终要达到的目的是与业务代码(单独运行)解耦单独运行，但是能够支持业务的权限管理

##### 快速开始
```bash
/apiRbac -c config.yaml
```
